## Description

Work on C6 Bank's Core Banking project focused on architectural evolution, technical standardization, and code sustainability. Active participation in defining standards and best practices, contributing to greater scalability, decoupling, and delivery quality.

## What I worked with

Work on evolving the MVP architecture, contributing to technical decisions aimed at reducing coupling, increasing testability, and supporting the project's long-term sustainability.

Cross-team collaboration to align architectural standards and organizational best practices.

Use of Tuist to organize and modularize the project, promoting better separation of domains and build time optimization.

Strengthening the quality culture with unit tests using QuickSpec and Nimble, along with technical support for developers as they evolved architectural solutions.

Dependency management with Swift Package Manager (SPM) and version control with Git, following branch workflow best practices.

Use of GitHub Copilot in the development workflow to accelerate implementation and assist code generation, while maintaining rigorous review and quality criteria.
