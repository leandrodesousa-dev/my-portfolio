## Description

Focus on developing new features and performing critical maintenance within a Core Banking project using the modern **SwiftUI** framework.

## What I worked with

I applied and developed with the modern **The Composable Architecture (TCA)** architecture pattern to ensure highly robust, testable, and scalable code. The focus on code quality was maintained through **unit tests** with **XCTest** and TCA's native testing tools. Dependencies were managed with both **CocoaPods** and **Swift Package Manager (SPM)**.
